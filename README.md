# SC26 Badge Kiosk releases

This is the official binary release feed for SC26 Badge Kiosk, published by AV Concepts.

Installers and matching SHA256 files are available under Releases. This repository contains no application source, credentials, attendee data, or runtime profiles. The kiosk reads this feed without signing in and never uploads data.

Existing 1.0.0 installations must install 1.1.0 manually once. Version 1.1.0 and later can discover future stable releases from this feed.

The current installer is unsigned; Windows may show an Unknown Publisher or SmartScreen prompt. Do not disable Windows security controls.
